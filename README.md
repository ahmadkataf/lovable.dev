# Emar 8 — تطبيق تفاعلي لتعلّم كتاب اللغة الإنجليزية (الصف الثامن)

تطبيق ويب بأسلوب **Duolingo** يغطّي كتاب *Emar English Series – Grade 8 – Student's Book* (وزارة التربية السورية 2025-2026) من أوّله إلى آخره:
6 وحدات (Modules) × 12 درساً (Units) × 7 دروس تفاعلية لكل درس + اختبار نهائي لكل وحدة.

## المزايا
- **مسار تعلّم** متسلسل (خريطة دروس) مع قفل/فتح تدريجي ونجوم لكل درس.
- **تمارين متنوعة**: بطاقات كلمات، اختيار المعنى، استماع واختيار، كتابة الكلمة، توصيل الأزواج، ترتيب الكلمات لتكوين جملة، قراءة وفهم، قواعد (ملء فراغ / اختيار / صح-خطأ)، استمع وكرّر (تعرّف صوتي عند توفّره).
- **صوت**: نطق كل كلمة وجملة ونص عبر Web Speech API (بدون إنترنت أو مفاتيح)، مع سرعة بطيئة 🐢، ومؤثرات صوتية.
- **نظام Duolingo**: قلوب ❤️ تتجدّد مع الوقت، نقاط XP، مستويات، سلسلة أيام 🔥، هدف يومي، إنجازات.
- **تكرار متباعد** للكلمات الضعيفة مع وضع «تدريب» يستعيد القلوب.
- **مرجع الكتاب**: نصوص القراءة الكاملة، القواعد بالعربية والإنجليزية، النطق، الكلمات مع الترجمة.
- يعمل على الهاتف والحاسوب، واجهة عربية RTL، وضع داكن تلقائي، PWA.

## التشغيل
```bash
npm install
npm run dev      # تطوير
npm run build    # إنتاج → dist/
npm test         # فحص سلامة بيانات المنهاج
```

## البنية
- `src/data/module1..6.ts` — محتوى الكتاب المنظّم (كلمات، نصوص، قواعد، تمارين) — انظر `src/data/DATA_SPEC.md`.
- `src/engine/` — الأنواع، مولّد التمارين، التقدّم (localStorage)، الصوت.
- `src/screens/` — الرئيسية (المسار)، الدرس، الكلمات، الكتاب، الملف الشخصي.
- `src/components/` — مكوّنات التمارين والعناصر المشتركة.

## الصوت المسجَّل
الكلمات والجمل والنصوص كلها لها تسجيلات صوتية جاهزة في `public/audio/` (ملف mp3 لكل وحدة + `index.json` بمواقع المقاطع)، ونطق المتصفح يُستخدم فقط كبديل لما ليس له تسجيل.
لإعادة توليدها بعد تعديل المحتوى:
```bash
pip install piper-tts imageio-ffmpeg numpy
# نزّل صوت Piper (مثلاً en_US-lessac-medium.onnx + .json) من rhasspy/piper-voices
node scripts/export-audio-texts.mjs          # يجمع كل النصوص في audio-src/texts.json
python3 scripts/gen-audio.py path/to/en_US-lessac-medium.onnx public/audio
```

## بناء تطبيق أندرويد (APK)
غلاف WebView بسيط في `android/` يقدّم التطبيق من `assets/www` على العنوان `https://emar8.app/` (بدون Gradle):
```bash
npm run build
ANDROID_HOME=/path/to/sdk ./scripts/build-apk.sh   # يحتاج build-tools 34.0.0 + platforms/android-34 + JDK 17+
# الناتج: android/build/Emar8.apk
```
