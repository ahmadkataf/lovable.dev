# Maths 3rd secondary (scientific) — Unit 1, Lesson 1 video «عموميّات عن المتتاليات»

An animated explainer of the first lesson of the Syrian Baccalaureate maths book (first term, pages 6–11),
1920×1080, 30 fps, with an Arabic (فصحى) voice-over generated by Gemini TTS.

| File | What it is |
|---|---|
| `lesson-content.md` | Faithful transcription of the book pages (Arabic + LaTeX). The source of truth. |
| `SCRIPT_SPEC.md` | Rules for the narration script (spoken-math conventions, TTS rules, content requirements). |
| `script.json` | The script: scenes → lines, each line = what the narrator says (`say`) + what is on screen (`screen`). |
| `SCENE_GUIDE.md` | How a scene is built (API of `lib.js`, layout rules, how to check stills). |
| `lesson.html`, `lib.js`, `main.js`, `scenes/*.js` | The animation. `render(t)` draws the frame at time `t`. |
| `build.py` | Voice pipeline: TTS sections → per-line clips (Whisper alignment) → `timeline.js` + `narration.wav` + `lesson.srt`. |
| `sound.py` | Synthesised ambient bed (ducks under the voice) + scene-change whooshes → `fx.wav`. |
| `render.mjs` | Renders the page to MP4 with parallel Chromium workers. |
| `voice/sections/*.flac` | The generated narration (one file per TTS request), kept so the video can be rebuilt without spending quota. |

## Voice
- Gemini TTS, model `gemini-3.8-flash-tts`, voice **`ar-001-tutor-2`** (Modern Standard Arabic, chosen by the owner after a
  three-voice test), style `clear, friendly instructor, moderate pace`. Locked in `build.py` — do not change mid-course.
- Free tier: **10 requests/day**, so the narration is sent in sections of ~5 minutes (one request each), never per line.
  `build.py gen` never regenerates an existing file and stops cleanly on exit code 3 (daily quota) — rerun after
  midnight Pacific time.
- The API key is read from `GEMINI_API_KEY` by `gemini_tts.py` (the helper from the voice-over brief, kept outside
  this repo). Never commit the key.
- Each section is cut into one clip per script line by aligning a Whisper (faster-whisper, `medium`) transcript to the
  script text, so every visual beat starts exactly when its sentence starts. `voice/split-report.tsv` flags any line
  whose speaking rate or ASR match looks wrong.

## Build
```bash
pip install numpy scipy faster-whisper
python3 build.py sections                              # → voice/sections/L01_s*.txt + manifest.csv
GEMINI_API_KEY=… python3 build.py gen --tts /path/to/gemini_tts.py
python3 build.py split                                 # → voice/lines/*.wav
python3 build.py timeline                              # → timeline.js/json, voice/narration.wav, lesson.srt
python3 sound.py                                       # → fx.wav
node render.mjs out/silent.mp4 --workers 3             # → video only (≈ 1 h on 4 cores)
ffmpeg -i out/silent.mp4 -i fx.wav -map 0:v -map 1:a -c:v copy -c:a aac -shortest out/video-fx.mp4
python3 add_voice.py --video out/video-fx.mp4 --clip voice/narration.wav --mode mix --bg-volume 1.0 --out out/L01.mp4
```
Before the voice exists, `python3 build.py timeline --estimate` times every line from its word count, so the
animation can be built and previewed (`node render.mjs --scene s05 /tmp/stills`).
