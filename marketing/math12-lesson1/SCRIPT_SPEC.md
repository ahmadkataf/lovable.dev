# Lesson-video script spec

The video is an explainer for **Lesson 1 «عموميّات عن المتتاليات»** of the Syrian 3rd-secondary scientific maths book
(first term). Source of truth: `lesson-content.md` (+ page images p006–p011).
Audience: Syrian Baccalaureate (scientific) students, 17–18 years old, who own the book.
Goal: the best lesson video they have ever seen for this lesson — clearer than a classroom teacher,
visually rich, precise, faithful to the book's notation, and engaging from the first second.

Format: 1920×1080, 30 fps, Arabic voice-over (one narrator, generated by a TTS API), animated
math graphics. No talking head. Target length **10–14 minutes**.

## File format — `script.json`

```json
{
  "title": "عموميّات عن المتتاليات",
  "scenes": [
    {
      "id": "s01",                       // s01, s02, … in order
      "section": "مقدمة",                 // short label shown in the corner chip (≤ 22 chars)
      "bookPage": 6,                      // page of the book this scene covers (null if none)
      "concept": "one paragraph: the visual idea of the whole scene (layout, objects, colors, motion)",
      "lines": [
        {
          "say": "النص الذي يُقرأ بصوت المعلّق…",
          "screen": "what is on screen while this line is spoken: exact Arabic text + LaTeX of every formula, what animates, what is highlighted",
          "hold": 0                       // optional extra seconds of silence after the line (pause-and-think, long animation). default 0
        }
      ]
    }
  ]
}
```

One line = one TTS clip = one visual beat. Lines are 1–3 sentences (≈ 4–15 s of speech). A scene
typically has 3–10 lines and lasts 30–90 s. Visual changes are cued at the **start** of each line,
so split lines wherever the picture must change.

## Rules for `say` (the narration)

- Modern Standard Arabic, simple and warm, like a brilliant teacher talking to one student
  («لاحظ معي»، «ركّز هنا»، «انتبه»). Short sentences. No filler, no hype words like «رائع جداً» every line.
- It is read by a TTS engine, so:
  - **No digits, symbols, Latin letters, LaTeX, emoji, brackets or abbreviations.** Write everything as spoken words.
  - Numbers in words: «سبعة وأربعون»، «ألفان ومئتان وسبعة».
  - Add tashkeel only where a word is ambiguous to a reader (e.g. «حدُّ»، «الحدِّ»، «أساسُ»، «تزايُد»), not everywhere.
  - Use Arabic punctuation (، . ؟) to give the voice natural pauses.
- Spoken math conventions (Syrian classroom style, use them consistently everywhere):
  - $u_n$ → «يو إنْ»، $u_{n+1}$ → «يو إنْ زائد واحد»، $u_0$ → «يو صفر»، $u_7$ → «يو سبعة»
  - $v_n$ → «في إنْ»، $w_n$ → «دبليو إنْ»، $n_0$ → «إنْ صفر»، $n$ alone → «إنْ»
  - $r$ → «آر»، $q$ → «كيو»، $f$ → «التابع إف»، $x$ → «إكس»، $a$ → «إيه»، $\ell$ → «إل»، $S$ → «إس»
  - $\alpha$ → «ألفا»، $\beta$ → «بيتا»، $\mathbb{N}$ → «مجموعة الأعداد الطبيعية»
  - $x^2$ → «إكس تربيع»، $x^3$ → «إكس تكعيب»، $q^n$ → «كيو أُس إنْ»، $\sqrt{\;}$ → «جذر»
  - $\frac{a}{b}$ → «إيه على بي» / «الكسر …»، $\le$ → «أصغر من أو يساوي»، $\ne$ → «لا يساوي»
  - $(u_n)_{n\ge0}$ → «المتتالية يو إنْ، حيث إنْ أكبر من أو يساوي الصفر»
- Never read a long formula symbol by symbol if the screen shows it; say what it *means* and read only the key part.

## Rules for `screen`

- Precise enough that an animator can build it without guessing: exact on-screen Arabic text,
  every formula in LaTeX (`$…$`), colors by role, what appears / moves / gets highlighted, and where.
- Use the book's notation exactly ($(u_n)_{n\ge0}$, $u_{n+1}=f(u_n)$, $[0,+\infty[$, «أساس», «مطّردة»…).
- On-screen Arabic text is short (titles, keywords, definitions in the book's own words). The narration explains; the screen anchors.
- Available building blocks (stay within these — no photos, no people, no characters, no stock footage):
  - Arabic title / subtitle / bullet text; **cards**: definition (تعريف), tip (💡), think (🤔 فكّر), example (مثال), warning (⚠️ انتبه), exam tip (🎯)
  - KaTeX formulas, display or inline; step-by-step algebra (each step appears / transforms into the next);
    color-coding parts of a formula; highlight boxes, underlines, circles, arrows pointing at a part
  - SVG graphics: number lines; arrows mapping indices $n$ to terms $u_n$; dot plots of points $(n, u_n)$ with axes;
    bar charts; staircases; grids/arrays of dots; a «function machine» box with input/output
  - tables whose cells fill in one by one; counters that count up; a pause-and-think countdown ring
  - a thumbnail of the relevant book page with a highlighted region («الكتاب ص 7»)
- Palette (dark navy background): yellow = the thing to look at now, purple = definitions/brand,
  green = correct / increasing, pink/red = decreasing / warning, blue = indices/secondary.

## Content requirements

1. **Hook (≤ 25 s)** from the page-6 activity (sum of the first n odd numbers), with a striking visual
   (odd numbers as L-shaped layers of dots building squares). End the hook with an open question
   that lesson 2 (proof by induction) will close.
2. Title card + roadmap of the lesson.
3. Cover **everything** on pages 7–10, in the book's order, with every definition, formula and example
   the book gives (incl. the «فكّر» question with its answer, the useful identity and its proof, and
   the three methods of «تكريساً للفهم» with their three examples). Add the worked algebra the book
   skips (e.g. the common-denominator steps for $u_{n+1}-u_n$) and explain *why* (e.g. why $n_0=1$ for
   $(1/n)$, why $(v_n)$ is increasing only from $n_0=1$: $v_0=1>v_1=0$).
4. Visual intuition for each idea (e.g. arithmetic = equal steps, geometric = repeated scaling,
   Gauss pairing for $1+2+\dots+n$, zig-zag for $(-1)^n$).
5. **Practice**: fully solve 3 exercises from page 11 (choose ones that best consolidate the lesson,
   e.g. ①, ②-1 and ③), with a pause-and-think beat before each solution. Every number must be exact.
6. Summary (one screen with the key formulas) + teaser of Lesson 2 (closing the two open questions) + a short
   outro inviting the student to practise the rest of «تدرّب» on the platform (do not name the platform).
7. Total narration ≈ 1500–2000 words.

## Completeness checklist — state curriculum, NOTHING may be dropped

The owner's hard requirement: the student must get **every** part of the lesson. Each item below must be
covered in `say` and shown in `screen`, faithfully (same notation, same conditions). Reviewers check this
list item by item.

**Page 6 (activity «التجربة والملاحظة والاستقراء»)**
- [ ] mathematics also uses observation, experiment and induction; «الاستقراء: استخلاص نتائج عامة من النظر في حالات خاصة»; only pen and paper needed
- [ ] odd numbers $\{1,3,5,7,9,\dots\}$, $S_n$ = sum of the first $n$ of them, the table for $n=1..4$ ($1, 4, 9, 16$)
- [ ] continue for $n=5,6,7$ ($25, 36, 49$), notice the pattern, conjecture $S_n=n^2$
- [ ] the question «كيف تُثبت صحّة استقرائك إثباتاً رياضياً؟» → answered in this unit (lesson 2)

**Page 7**
- [ ] definition: a sequence is a function whose domain is $\mathbb{N}$ or an infinite subset $\{n_0, n_0+1, n_0+2,\dots\}$, $n_0$ given and may change from one sequence to another
- [ ] notation $(u_n)_{n\ge0}$ / $(u_n)_{n\ge n_0}$; «$u_n$ حدّ المتتالية ذو الدليل $n$»
- [ ] a sequence has infinitely many terms whatever their values: $u_n=(-1)^n$ takes only $+1$ and $-1$
- [ ] $\left(\frac1n\right)_{n\ge1}$ has $n_0=1$ and $\left(\frac{1}{n^2-1}\right)_{n\ge2}$ has $n_0=2$ (+ why)
- [ ] 1.1 ① explicit definition: $u_n=\frac{(-1)^n}{n+1}$; $u_n=f(n)$ with $f$ defined on $[0,+\infty[$, e.g. $f(x)=\sqrt{x^2+x+1}$
- [ ] 1.1 ② recursive definition: give $u_0$ and a «علاقة تدريجيّة» computing each term from the one(s) before
- [ ] example $u_0=3$, $u_{n+1}=u_n^2-2$: $u_1=7$, $u_2=47$, $u_3=2207$; here $u_{n+1}=f(u_n)$ with $f:x\mapsto x^2-2$
- [ ] general case: $f$ defined on $D$ with «مهما يكن $x$ من $D$ يكن $f(x)$ من $D$», $u_0\in D$, $u_{n+1}=f(u_n)$ (+ why the condition is needed)

**Page 8**
- [ ] «فكّر»: are the units digits of all terms with index > 1 equal to 7? (+ the answer and why; link to lesson 2)
- [ ] تعريف 1, all five: strictly increasing ($u_n<u_{n+1}$), strictly decreasing ($u_n>u_{n+1}$), increasing ($\le$), decreasing ($\ge$), constant ($=$), each «مهما تكن $n_0\le n$», each «إذا وفقط إذا»
- [ ] the word «مطّردة» for a sequence satisfying one of them; $(-1)^n$ is not monotonic
- [ ] tip: compare $u_n$ and $u_{n+1}$ via the sign of $u_{n+1}-u_n$, or via $\frac{u_{n+1}}{u_n}$ vs $1$ **when all terms are strictly positive**
- [ ] تعريف 2: arithmetic sequence, $u_{n+1}=u_n+r$ for every natural $n$, $r$ = «أساس»; «ننتقل من حدٍّ إلى الحدّ الذي يليه بإضافة العدد الحقيقي نفسه»

**Page 9**
- [ ] $u_m=u_p+(m-p)r$ for all naturals $m,p$
- [ ] $S=\frac{n(a+\ell)}{2}$ for $n$ consecutive terms, first $a$, last $\ell$; special case $1+2+\cdots+n=\frac{n(n+1)}{2}$
- [ ] تعريف 3: geometric sequence, $u_{n+1}=q\times u_n$, $q$ = «أساس»; «ننتقل … بالضرب بالعدد الحقيقي ذاته»
- [ ] $u_m=u_p\,q^{m-p}$ for all naturals $m,p$
- [ ] $S=a\,\frac{1-q^n}{1-q}$ for $n$ consecutive terms, first $a$, **$q\ne1$**; special case $1+q+\cdots+q^{n-1}=\frac{1-q^n}{1-q}$
- [ ] «مطابقة مفيدة»: $x^n-a^n=(x-a)(x^{n-1}+x^{n-2}a+\cdots+a^{n-1})$; meaning: sum of all $x^\alpha a^\beta$ with $\alpha+\beta=n-1$; example $x^5-a^5$
- [ ] its proof: obvious for $x=a$ or $x=0$; otherwise put $q=\frac{a}{x}$ in the geometric sum

**Page 10**
- [ ] proof end: $1+\frac ax+\cdots+\frac{a^{n-1}}{x^{n-1}}=\frac{x^n-a^n}{x^{n-1}(x-a)}$, then multiply both sides by $x^{n-1}(x-a)$
- [ ] «تكريساً للفهم: كيف ندرس جهة اطراد متتالية؟» — three methods:
- [ ] ① sign of $u_{n+1}-u_n$ with the full example $u_n=\frac{n^2+1}{2n}$, $n\ge1$ → $\frac{n^2+n-1}{2n(n+1)}$, sign of $n^2+n-1$, positive since $n-1\ge0$ and $n^2>0$ → strictly increasing
- [ ] ② $u_n=f(n)$ and the monotonicity of $f$ on $[n_0,+\infty[$, example $v_n=(n-1)^2$, $f'(x)=2(x-1)>0$ for $x>1$ → strictly increasing from $n_0=1$
- [ ] ③ strictly positive terms: compare $\frac{u_{n+1}}{u_n}$ with 1, example $w_n=\left(\frac23\right)^n$, ratio $\frac23<1$ → strictly decreasing

**Page 11 «تدرّب»** — this video solves 3 representative exercises (e.g. ①, ②-1 and ③); a separate
solutions video solves all of them. The outro must tell the student that every «تدرّب» exercise is solved
step by step in the next video.
