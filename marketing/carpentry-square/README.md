# Carpentry workshop square post (1080×1080)

Modern Scandinavian-style furniture promo, in Arabic, with no third-party brand names.

- `design.html` holds the source. Edit the text, phone number and colors here.
- `carpentry-square.png` is the exported image at 2160×2160.

Re-export after edits:

```
node render.mjs "$PWD/design.html" "$PWD/carpentry-square.png"
```

The phone number `0000 000 000` and the wordmark "منجرة" are placeholders for the real workshop name and number.
