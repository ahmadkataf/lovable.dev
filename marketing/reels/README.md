# Instagram reels (1080x1920)

Reel-words (word test), Reel-exam (5-second exam question), Reel-idiom (on a roll).
Sounds: Mixkit ids in mix.py (download as in ../promo-g12/square-v2/README.md into sfx/, with sfx/info.json from there). Voice: Kokoro af_heart.
Render: `node rr.mjs <words|exam|idiom> <framesDir> 0-<frames>`, then encode with a-<name>.wav from `python3 mix.py`.
