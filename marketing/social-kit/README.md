## 6. ردود جاهزة على الرسائل

**كم السعر؟**
```
أهلين 🌷 الوحدة الأولى مجانية لتجرّب. الاشتراك للعام الدراسي كامل: البكالوريا 20$، التاسع والحادي عشر 15$، الخامس والثامن 5$.
```

**كيف بدفع؟**
```
من التطبيق: اكبس «فعّل» ← ادفع بشام كاش من الرمز ← اكبس «دفعت» واكتب اسمك ورقمك. أول ما نتأكد من الدفع، التطبيق بيتفعّل لحاله 🎉
```

**عندي آيفون**
```
افتح الرابط من سفاري، واكبس «مشاركة» ← «إضافة إلى الشاشة الرئيسية»، فبيصير متل التطبيق.
```

**عندي كود من المكتبة**
```
افتح التطبيق وانت متصل بالإنترنت ← «فعّل» ← «عندك كود من مكتبة أو أستاذ؟» ← اكتب الكود.
```

## 7. قواعد مهمة

- لا تشتري متابعين ولا تعليقات. المنصات بتكشفهن وبتخفّض وصول منشوراتك.
- لا تنشر أرقام مشتركين غير الحقيقية، لأن الأهالي والطلاب بيلاحظوا.
- رد على الرسائل بنفس اليوم، فأغلب الاشتراكات بتجي من الرسائل.
- الفيديوهات بتوصل لناس أكتر من الصور، فنزّل فيديو مرتين بالأسبوع على الأقل.
