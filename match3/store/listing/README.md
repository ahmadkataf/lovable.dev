# نصوص صفحة المتجر — أين كل شيء

هذا المجلد فيه **مجموعة واحدة معتمدة** من نصوص صفحة «زمرد» على Google Play.

| الملف | ما هو | من يستعمله |
|---|---|---|
| <span dir="ltr">`fields.json`</span> | كل النصوص سلاسلَ جاهزة للّصق، بمفتاحَي اللغتين <span dir="ltr">`"en-US"`</span> و<span dir="ltr">`"ar"`</span>: <span dir="ltr">`title`</span>، <span dir="ltr">`shortDescription`</span>، <span dir="ltr">`fullDescription`</span>، <span dir="ltr">`releaseNotes`</span>. فيه أيضًا: أعداد الأحرف، الفئة والوسوم، نص خانة ملاحظات الإصدار بوسمَي اللغتين (<span dir="ltr">`releaseNotesBox`</span>)، والوصف البديل لنسخة بلا إعلانات (<span dir="ltr">`ifTheBuildHasNoAds`</span>). **يُولَّد آليًّا ولا يُعدَّل باليد.** | المساعد الآلي الذي يملأ Play Console |
| <span dir="ltr">`en-US.md`</span> | النص الإنجليزي النهائي (اللغة الافتراضية) مع شرح كل اختيار بالعربية، والفئة والوسوم وبيانات التواصل. **هو المصدر.** | أنت، ومن يعدّل النص |
| <span dir="ltr">`ar.md`</span> | النص العربي النهائي، مكتوب بالعربية أصلًا لا مترجمًا. **هو المصدر.** | أنت، ومن يعدّل النص |
| <span dir="ltr">`ar-variants.md`</span> | بدائل عربية للاسم والوصف القصير لتجارب ما بعد النشر، وطريقة التجربة. | أنت، بعد النشر |
| <span dir="ltr">`en-US-variants.md`</span> | بدائل إنجليزية للاسم والوصف القصير. | أنت، بعد النشر |
| <span dir="ltr">`en.md`</span> | **ليس ملفًّا ثانيًا**: اسم مستعار (رابط رمزي) يشير إلى <span dir="ltr">`en-US.md`</span> نفسه، أُبقي لأن أدوات وأدلة قديمة ما زالت تذكر الاسم القديم. النص القديم الذي كان فيه حُذف. | الأدوات القديمة فقط |

لماذا هذه الكلمات؟ الخطة والأرقام والمستبعدات في <span dir="ltr">`store/aso/KEYWORDS.md`</span>.

## بعد أي تعديل على نص

من مجلد <span dir="ltr">`match3`</span>:

<div dir="ltr">

```
node store/aso/check-listing.cjs --write         # يعيد عدّ الأحرف ويولّد fields.json ثم يفحص كل شيء
node store/aso/check-listing.cjs --cross-check   # الفحص نفسه + فاحص الحزمة tools/store/check-kit.cjs
node store/aso/selftest.cjs                      # يثبت أن الفاحص يرفض النص المخالف (34 حالة)
```

</div>

الفاحص يعدّ الأحرف، ويمنع الكلمات المحظورة وأسماء الألعاب الأخرى، ويقارن كل رقم في النص (120 مرحلة، ستة عوالم، خمسة قلوب…) بملفات اللعبة نفسها، ويتأكد أن <span dir="ltr">`fields.json`</span> يطابق الملفين حرفيًّا.

## ملاحظة للمساعد الآلي

- الصق من <span dir="ltr">`fields.json`</span> فقط، كل سلسلة كما هي، دون إعادة صياغة أو ترجمة أو «تصحيح».
- لا تُدخل أي كلمة من <span dir="ltr">`store/aso/KEYWORDS.md`</span> في أي خانة: Google Play ليس فيه خانة كلمات مفتاحية.
- النص العربي قد يبدو مقلوب الترقيم داخل خانة اتجاهها من اليسار؛ هو سليم، فلا تغيّر ترتيب أحرفه.
