# لقطات الشاشة — تُلتقط لاحقًا

هذا المجلد فارغ عمدًا الآن: لقطات المتجر يجب أن تكون **لقطات حقيقية من اللعبة نفسها**، وتُلتقط بعد اكتمال دمج واجهة اللعبة بالأمر (من مجلد `match3`):

<div dir="ltr">

```
node tools/store/make-screenshots.cjs
node tools/store/check-kit.cjs screenshots
```

</div>

الناتج: ست لقطات لكل لغة بمقاس **<span dir="ltr">1080×1920</span>** (PNG 24-بت بلا شفافية):

| الملف | المشهد |
|---|---|
| `en/01-play.png` · `ar/01-play.png` | اللعب داخل مرحلة |
| <span dir="ltr">`02-map.png`</span> | خريطة المراحل |
| <span dir="ltr">`03-level-intro.png`</span> | مقدّمة المرحلة (الأهداف والمعزّزات) |
| <span dir="ltr">`04-win.png`</span> | نافذة الفوز |
| <span dir="ltr">`05-shop.png`</span> | المتجر |
| <span dir="ltr">`06-title.png`</span> | شاشة البداية |

الأرقام هي ترتيب الرفع المقترح. ارفع لقطات <span dir="ltr">`en/`</span> في البطاقة الإنجليزية ولقطات <span dir="ltr">`ar/`</span> في البطاقة العربية (`Phone screenshots`).

شروط Google Play المطبّقة: لقطتان على الأقل (وثلاث لقطات طولية <span dir="ltr">1080×1920</span> أو أكبر لتتأهل اللعبة لمساحات التوصية الكبيرة)، حتى 8 لقطات، بلا إطار جهاز ولا أصابع، وبلا عبارات ترتيب أو سعر أو «حمّل الآن». راجع كل لقطة بعينك قبل رفعها.
