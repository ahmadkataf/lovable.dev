# SUFIX — موقع صيانة وبيع الإلكترونيات والدرونات

متجر إلكتروني + طلب خدمة صيانة + لوحة إدارة كاملة، بالعربية (RTL)، مصمَّم للعمل بدون دفع إلكتروني:
العميل يسجّل طلبه على الموقع ثم يضغط **«إتمام الطلب عبر واتساب»** فتصل تفاصيله للبائع، ويبقى الطلب مسجّلاً بحالته على الموقع.

## ما الذي يحتويه الموقع
- **المتجر**: أقسام، بحث، تصفية حسب القسم والماركة وطراز DJI، صفحة منتج بصور ومواصفات وتوافق، سلة، إتمام الطلب برقم تتبّع.
- **درونات DJI**: كل السلاسل والطرازات (Mini, Air, Mavic, Flip, Neo, Avata, FPV, Inspire, Phantom, Matrice, Agras…) مع القطع المتوافقة لكل طراز.
- **طلب صيانة**: نموذج بنوع الجهاز والماركة والطراز ووصف العطل وصور، رقم تتبّع، وإرسال للفني عبر واتساب.
- **تتبّع الطلب**: برقم الطلب ورقم الهاتف، مع خط زمني للحالة.
- **لوحة الإدارة** `/admin`:
  - لوحة تحكم بالمؤشرات، وزر **حذف النسخة الافتراضية بالكامل** (مع إمكانية استعادتها).
  - الطلبات: تغيير الحالة (جديد ← مؤكّد ← قيد التجهيز ← تم الشحن ← تم التسليم / ملغى)، مراسلة العميل، ملاحظات، طباعة. التأكيد يخصم المخزون، والتسليم يسجّل الإيراد في الدفتر تلقائياً.
  - الصيانة: استلام أجهزة، حالات (استلام ← فحص ← بانتظار الموافقة ← إصلاح ← جاهز ← تسليم)، تقدير وتكلفة نهائية وكلفة قطع.
  - المنتجات والأقسام: إضافة وتعديل مع رفع صور وتحديد الطرازات المتوافقة.
  - **دفتر الصادر والوارد**: قيود يدوية وتلقائية، فترات، تصدير CSV.
  - **التقارير**: وارد/صادر يومياً، مبيعات شهرياً، الأكثر مبيعاً، حسب التصنيف.
  - **تخصيص الموقع**: الاسم والشعار والألوان والسمة، نصوص الصفحة الرئيسية وأقسامها، الخدمات، لماذا نحن، آراء العملاء، الأسئلة الشائعة، من نحن، العملة، الشحن والمحافظات، نموذج الصيانة، كلمة المرور، نسخ احتياطي.

## التشغيل محلياً
```bash
cd sufix
npm install
npm run build && npm run server      # http://localhost:8787 — الموقع والـ API معاً، البيانات في server/data/sufix.db
# أو للتطوير مع إعادة تحميل فورية:
npm run server   # في نافذة
npm run dev      # في نافذة أخرى → http://localhost:5173 (يمرّر /api إلى 8787)
npm test
```
أول مرة تفتح `/admin` سيُطلب منك إنشاء كلمة مرور الإدارة.

## النشر على Cloudflare (مجاني)
الموقع والـ API يعملان على Cloudflare Workers وقاعدة بيانات D1:
1. أضف في المستودع ← Settings ← Secrets and variables ← Actions:
   `CLOUDFLARE_API_TOKEN` (صلاحيات Edit Cloudflare Workers + D1 Edit) و `CLOUDFLARE_ACCOUNT_ID`.
2. من Actions شغّل **Deploy SUFIX**. يظهر في نهاية السجل عنوان مثل `https://sufix.<اسمك>.workers.dev`.
3. اربط نطاقك الخاص من لوحة Cloudflare ← Workers ← sufix ← Settings ← Domains.

بعدها كل تعديل في `sufix/` يُنشر تلقائياً. بدون خادم (استضافة ثابتة فقط) يعمل الموقع في **وضع المعاينة** ويحفظ البيانات في متصفح الزائر فقط.

## البنية
- `shared/` — الأنواع، طرازات DJI، الإعدادات الافتراضية، النسخة الافتراضية، حسابات التقارير (مشتركة بين الواجهة والـ API).
- `worker/` — الـ API (Cloudflare Worker / D1). `server/node.mjs` يشغّل نفس الـ API على Node مع SQLite.
- `src/` — الواجهة (React + Vite): `pages/` الموقع، `admin/` لوحة الإدارة، `lib/` الموجّه والمخزن وعميل الـ API.

## إعادة تعيين كلمة مرور الإدارة
```bash
npx wrangler d1 execute sufix --remote --command "DELETE FROM settings WHERE key='admin_password'; DELETE FROM sessions"
```
ثم افتح `/admin` لإنشاء كلمة مرور جديدة. (محلياً: احذف `server/data/sufix.db` أو نفّذ الأمر نفسه على الملف.)
