# كراج الرضوان — نظام إدارة محل قطع غيار السيارات

برنامج كامل لإدارة محل قطع الغيار، يعمل على **ويندوز** و**أندرويد** و**كموقع إلكتروني** بنفس البيانات:

- **بيع جديد (نقطة بيع)**: بحث سريع بالاسم أو الكود أو الباركود أو نوع السيارة، سلة، خصم، دفع كامل أو آجل، حفظ وطباعة، إرسال الفاتورة واتساب.
- **فواتير المبيعات**: عرض، تعديل، طباعة، مرتجع، تصدير إكسل.
- **المنتجات**: قطع وخدمات (أجرة عمل)، تصنيفات، ماركة، السيارات المناسبة، مكان القطعة، صورة، سعر شراء/بيع/جملة، استيراد وتصدير إكسل.
- **المخزون**: كميات فورية، تنبيهات نقص، جرد، سجل حركات كل قطعة.
- **المشتريات**: فواتير الموردين تُدخل الكميات إلى المخزون وتحدّث الكلفة.
- **العملاء والموردون**: أرصدة، كشف حساب، تحصيل وتسديد دفعات، رسائل واتساب.
- **الصندوق والمصاريف**: رصيد الصندوق، حركات اليوم، مصاريف بأنواعها، إيداع وسحب.
- **التقارير**: مبيعات وأرباح وصافي ربح لأي فترة، الأكثر مبيعاً، أفضل العملاء، المصاريف، تقرير شهري.
- **مستخدمون بأرقام سرية وصلاحيات لكل موظف**: المدير يحدد لكل موظف ما يستطيع فعله (بيع، عروض أسعار، مرتجعات، تعديل الفواتير، تغيير التاريخ، إضافة القطع، تعديل الأسعار، رؤية الأرباح، الجرد، المشتريات، الدفعات، المصاريف، التقارير، المحاسبة…)، مع زر قفل الشاشة لتبديل المستخدم وقفل تلقائي بعد خمول؛ الحذف والإعدادات للمدير فقط.
- **الليرة والدولار**: الأسعار تُحفظ بعملة أساسية (ليرة أو دولار)، وسعر الدولار يُغيَّر في أي وقت من الشريط العلوي، وتُعرض الأسعار بالليرة أو بالدولار أو بكليهما، وكل فاتورة تحفظ سعر الصرف يوم إصدارها.
- **طباعة** A4 أو إيصال حراري 80mm، شعار المحل على الفاتورة.
- **يعمل بلا إنترنت**، والبيانات محفوظة على الجهاز، مع **نسخ احتياطي** بملف واحد.
- **مزامنة اختيارية** بين الأجهزة عبر خادم Cloudflare مجاني (نفس البيانات على الحاسوب والهاتف والموقع).
- **سجل النشاط**: من فعل ماذا ومتى وعلى أي جهاز (فواتير، دفعات، جرد، تعديل أسعار، سعر الدولار، دخول…).
- **المحذوفات**: لا يُحذف شيء نهائياً؛ المدير يستعيد أي فاتورة أو قطعة أو عميل بضغطة.
- **ملصقات باركود** (Code 128) للرفوف، و**تقرير إغلاق اليوم** للطباعة، و**ديون متأخرة** (+30 يوماً) على الرئيسية.
- **دليل السيارات**: قراءة رقم الشاصي بلا إنترنت من قاعدة بيانات داخل التطبيق (أكثر من 400 رمز مُصنّع من كل العالم، والموديل وجيله لهيونداي وكيا وتويوتا ونيسان وهوندا وميتسوبيشي ومرسيدس وBMW وفولكس واجن وأودي وسكودا ومازدا وسوزوكي وشيفروليه/دايو ولادا ورينو وبيجو وستروين والصينيات والإيرانيات…)، ويكمّلها مفكّك NHTSA المجاني بالمحرك عند توفر الإنترنت، موديلات المحل وربط القطع بها، فتح الكتالوج المصوّر (PartSouq/Amayama) على الشاصي نفسه، أرقام القطع الأصلية OEM والبحث بها في البيع، وتصفية شاشة البيع حسب السيارة.
- **خصم دائم للعميل** ورقم لوحة السيارة، واختصارات لوحة المفاتيح في شاشة البيع (F2 بحث، F8 حفظ، F9 حفظ وطباعة).
- **المحاسبة (للمدير)**: دفتر يومية مزدوج القيد يُشتق تلقائياً من الفواتير والدفعات والمصاريف والجرد (لا شيء يُدخل مرتين)، دفتر أستاذ لكل حساب، ميزان مراجعة، قائمة دخل (مبيعات، تكلفة البضاعة، مجمل الربح، مصاريف، صافي الربح)، ميزانية (المركز المالي)، أعمار ديون العملاء (30/60/90 يوماً)، وقيود يدوية بقوالب جاهزة؛ كل تقرير يُطبع ويُصدَّر إكسل.
- **عروض الأسعار**: من شاشة البيع فعّل «عرض سعر» فيُحفظ ويُطبع ويُرسل واتساب دون أن يمس المخزون أو الصندوق، ويُحوَّل لاحقاً إلى فاتورة بضغطة. و**خصم بالنسبة المئوية** أو بالمبلغ.
- **سيارات العملاء وسجل الصيانة**: لكل عميل سيارة أو أكثر (شاصي، لوحة، عداد)، كل فاتورة تُسجَّل على سيارتها بعدادها، وتذكير الصيانة القادمة بالكيلومترات أو بالأيام يظهر على الرئيسية مع رسالة واتساب جاهزة للعميل.
- **أوامر العمل (Job Cards)**: أمر عمل مفتوح للسيارة تُضاف إليه القطع والأجور مع تقدم العمل (مفتوح / قيد العمل / جاهز للتسليم)، ثم يُغلق كفاتورة بضغطة.
- **اقتراح طلبية**: في المخزون، الكميات التي تحتاج طلباً مجمّعة حسب آخر مورد مع تقدير الكلفة، وإرسالها للمورد واتساب أو إكسل.
- **عدة باركودات للقطعة الواحدة** (تُفصل بفاصلة) وكلها تُمسح في البيع.
- **مظهر فاتح وداكن** بزر واحد في الشريط العلوي (الفاتح هو الافتراضي).
- **طباعة مستقرة على ويندوز**: الفاتورة تُفتح في نافذة معاينة PDF (طباعة أو حفظ) بدل نافذة الطابعة التي قد تختفي خلف البرنامج، مع خيار الطباعة المباشرة من الإعدادات.

واجهة عربية كاملة (RTL)، وضع فاتح وداكن، وتصميم يناسب الهاتف والحاسوب.

## الأمان

- مفتاح المزامنة وعنوان الخادم يبقيان على الجهاز نفسه ولا يُرسلان إلى الخادم ولا يدخلان في ملفات النسخ الاحتياطي (أدخل المفتاح على كل جهاز مرة واحدة).

- **الأرقام السرية** مخزّنة بـ PBKDF2-SHA256 مع ملح عشوائي (150 ألف دورة)؛ السجلات القديمة تُرقّى تلقائياً عند أول دخول ناجح.
- **حماية من التخمين**: بعد 5 محاولات خاطئة تنتظر لوحة الأرقام 30 ثانية، وتتضاعف المدة مع كل محاولة، وتُسجَّل في سجل النشاط.
- **قفل تلقائي** بعد دقائق من الخمول (الإعدادات ← المحل).
- **صلاحيات**: الموظف لا يرى الأرباح ولا التقارير ولا سجل النشاط ولا المحذوفات، ولا يحذف شيئاً؛ ويمكن منعه من تعديل الأسعار.
- **نسخ احتياطي مشفّر** بكلمة سر (AES-256-GCM) لإرساله عبر واتساب أو حفظه عند الغير، ونسخ تلقائية يومية على ويندوز (آخر 14 يوماً).
- **الخادم**: مفتاح المحل 12 حرفاً على الأقل ولا يُخزَّن إلا مجزّأً، حد لمحاولات التخمين من العنوان الواحد، حدود لحجم الطلبات والسجلات، HTTPS إجباري، وتحذير في البرنامج إن كانت ساعة الجهاز غير مضبوطة.
- **التطبيق**: سياسة أمان للمحتوى (CSP) تمنع أي سكربت خارجي، وعزل كامل بين الواجهة ونظام التشغيل في نسخة ويندوز، والحاجز نفسه في أندرويد (لا وصول للملفات من الصفحة).

## كيف أحصل على الملفات؟

من صفحة **Actions** في GitHub شغّل `Build AlRadwan Garage apps` (زر *Run workflow*). بعد نحو 10 دقائق تجد في صفحة **Releases**:

| الملف | الاستخدام |
|---|---|
| `AlRadwan-Garage-<الإصدار>-setup.exe` | تثبيت على ويندوز (اختصار على سطح المكتب) |
| `AlRadwan-Garage-<الإصدار>-portable.exe` | نسخة محمولة تعمل مباشرة بلا تثبيت (فلاشة) |
| `AlRadwan-Garage.apk` | تطبيق أندرويد، يُثبَّت من الملف مباشرة (اسمح بالتثبيت من مصادر غير معروفة عند الطلب؛ ليس على Google Play) |
| `alradwan-web.zip` | ملفات الموقع الجاهزة لأي استضافة ثابتة |

> ويندوز قد يعرض تحذير SmartScreen لأن الملف غير موقّع بشهادة تجارية: اضغط *More info → Run anyway*.

**المتطلبات:** ويندوز 10 أو 11 (64 بت)؛ أندرويد 7 فما فوق؛ وللموقع متصفح حديث (Chrome أو Edge أو Safari). لا يحتاج إنترنت للعمل اليومي.

**التحديث لا يمسّ البيانات.** البيانات محفوظة خارج ملفات البرنامج (على ويندوز في `%APPDATA%\كراج الرضوان`، وعلى أندرويد داخل بيانات التطبيق):
- ويندوز: ثبّت النسخة الجديدة فوق القديمة مباشرة؛ الفواتير والقطع والإعدادات والتفعيل كلها تبقى، وحتى إزالة البرنامج لا تحذفها. النسخة المحمولة تحفظ بياناتها في المجلد نفسه، فاحتفظ بها في مكانها.
- أندرويد: ثبّت الـ APK الجديد فوق القديم. يشترط أن يكون موقّعاً بالمفتاح نفسه (انظر الأسرار أدناه)؛ وإلا يرفض أندرويد التثبيت ويلزم الحذف أولاً، فخذ نسخة احتياطية قبل ذلك.
- الموقع: يحدّث نفسه ويعرض «نسخة جديدة جاهزة».
- قاعدة البيانات تُرقَّى تلقائياً عند أول فتح بعد التحديث (كل إصدار يعرف الإصدارات التي سبقته).

## أول تشغيل

1. اكتب اسم المحل والهاتف والعملة.
2. ضع رقماً سرياً لصاحب المحل (اختياري)، وأضف الموظفين لاحقاً من الإعدادات → المستخدمون.
3. فعّل «بيانات تجريبية» لتجربة البرنامج، ثم احذفها من الإعدادات → النسخ الاحتياطي عند البدء الفعلي.
4. أدخل القطع من شاشة **المنتجات** (أو استوردها من ملف إكسل: نموذج جاهز من الشاشة نفسها).

## البيع بأكواد التفعيل (لوحة التحكم)

البرنامج يُباع بأكواد كما في تطبيق Emar: كل كود يعمل على جهازين (حاسوب + هاتف) افتراضياً، لمدة شهر أو سنة أو دائم.
لا فترة تجريبية: أي نسخة بلا كود تعرض شاشة التفعيل فوراً (السعر 35$، واتساب، شام كاش)؛ بيانات المشتري لا تضيع أبداً عند انتهاء الاشتراك.

1. أضف في المستودع ← Settings ← Secrets and variables ← Actions ← **Secrets** الأسرار الأربعة نفسها التي يستخدمها خادم Emar (إن كانت موجودة فلا شيء يُضاف):
   - `CLOUDFLARE_API_TOKEN` (صلاحيات Edit Cloudflare Workers وD1 Edit) و`CLOUDFLARE_ACCOUNT_ID`.
   - `EMAR_ADMIN_KEY` (كلمة سر لوحة التحكم، تُستخدم للوحتين) و`EMAR_TOKEN_SECRET` (يشتق منه الخادم سرّه الخاص فلا يتشارك المفتاح مع Emar).
   - اختيارياً `ALRADWAN_ADMIN_KEY` و`ALRADWAN_TOKEN_SECRET` إن أردت كلمة سر وسرّاً مستقلّين؛ لهما الأولوية.
   - للأندرويد: `ALRADWAN_KEYSTORE_BASE64` و`ALRADWAN_KEYSTORE_PASSWORD` و`ALRADWAN_KEY_ALIAS` (أو أسرار Emar `ANDROID_KEYSTORE_*`): مفتاح التوقيع الدائم، وبدونه كل بناء موقّع بمفتاح مختلف ولا يُحدَّث فوق القديم. يُصنع مرة واحدة:
     `keytool -genkeypair -keystore alradwan.keystore -alias alradwan -keyalg RSA -keysize 2048 -validity 10000` ثم `base64 -w0 alradwan.keystore` هو قيمة السر الأول.
2. شغّل سير **Deploy AlRadwan Garage website**: ينشر الخادم على `https://alradwan.almutafawiqin.workers.dev` (عنوان حساب Cloudflare نفسه الذي يعمل عليه Emar). ثم **Build AlRadwan Garage apps**: يجد الخادم بنفسه ويبني نسخاً تطلب التفعيل؛ وما دام الخادم غير منشور تُبنى نسخة مجانية بلا تفعيل مع تحذير في سجل البناء. (المتغير `ALRADWAN_API` يبقى خياراً لمن يريد عنواناً آخر.)
3. افتح `https://alradwan.almutafawiqin.workers.dev/admin` وأدخل كلمة سر اللوحة: أنشئ الأكواد (العدد، المدة، عدد الأجهزة، اسم المحل)، انسخها أو اطبعها بطاقات، ابحث وألغِ ومدّد وفُكّ الأجهزة، وراقب الإحصاءات والاشتراكات التي تنتهي قريباً.
4. بيانات البيع التي تظهر للمشتري (رقم واتساب، السعر، عنوان شام كاش ورمزه، مدة التجربة) في `src/sales.ts` و`public/shamcash-qr.png`. الافتراضي: لا فترة تجريبية — أي نسخة بلا كود تعرض شاشة التفعيل فوراً (حتى بعد التحديث)، والتفعيل يحتاج إنترنت مرة واحدة.
5. **أكواد الطوارئ بلا إنترنت:** `src/offlineCodes.ts` يحمل بصمات (SHA-256) أكواد تُفعّل الجهاز نهائياً بلا اتصال، للمحلات التي لا إنترنت لديها إطلاقاً. الأكواد نفسها ليست في المستودع؛ احتفظ بها عندك، وإن تسرّب أحدها استبدل القائمة وأعد البناء. لصنع كود جديد وبصمته:
   `node -e "const c=require('crypto');const code=c.randomBytes(9).toString('base64').replace(/[^A-Z0-9]/gi,'').slice(0,12).toUpperCase().replace(/(.{4})(.{4})(.{4})/,'$1-$2-$3');console.log(code, c.createHash('sha256').update('alradwan-offline:'+code.replace(/-/g,'')).digest('hex'))"`

كيف يعمل: الكود عشوائي (12 حرفاً) محفوظ على الخادم فلا يُزوَّر؛ التفعيل يحتاج إنترنت مرة واحدة، ثم يعمل البرنامج بلا إنترنت ويتحقق كل 6 ساعات عندما يتوفر الاتصال، وإن انقطع الإنترنت 14 يوماً يطلب الاتصال. الكود الملغى أو المنتهي يوقف البرنامج عند أول تحقق.

## الموقع الإلكتروني والمزامنة (Cloudflare)

الموقع والمزامنة يعملان معاً على Cloudflare Workers + D1 (الخطة المجانية تكفي محلاً كاملاً).

**الطريقة السهلة**: مع وجود أسرار Cloudflare والترخيص في المستودع (القسم السابق)، شغّل `Deploy AlRadwan Garage website` من تبويب Actions؛ وهو يعمل وحده أيضاً عند كل تغيير في التطبيق أو الخادم. أول تشغيل يُنشئ قاعدة البيانات بنفسه، وعنوان الموقع يظهر في ملخص التشغيل (`https://alradwan.almutafawiqin.workers.dev`). بلا الأسرار ينتهي السير فوراً برسالة تذكير ولا يُنشر شيء.

**يدوياً**:
```bash
cd alradwan/server
npm install
npx wrangler login
npx wrangler d1 create alradwan        # انسخ database_id الناتج إلى wrangler.toml
npx wrangler d1 execute alradwan --remote --file=schema.sql
cd .. && npm install && npm run build
cd server && npx wrangler deploy
```

بعد النشر: على كل جهاز افتح الإعدادات → **المزامنة بين الأجهزة**، ضع عنوان الموقع، ولّد **مفتاح المحل** على الجهاز الأول وانسخه إلى بقية الأجهزة. المفتاح هو كلمة سر بياناتك؛ لا تعطه لأحد.

## التطوير

```bash
cd alradwan
npm install
npm run dev          # http://localhost:5180
npm test             # اختبارات الحسابات
npm run build        # الموقع → dist/
npm run electron     # تشغيل نسخة ويندوز/سطح المكتب محلياً
npm run build:win    # ملفات ويندوز → release/ (على ويندوز؛ على لينكس يحتاج wine)
npm run build:apk    # APK → android/build/ (يحتاج ANDROID_HOME وJDK 17)
```

### البنية
- `src/db/` — نموذج البيانات (`types.ts`)، قاعدة البيانات المحلية IndexedDB (`db.ts`)، المخزن في الذاكرة (`store.ts`)، العمليات (`actions.ts`).
- `src/lib/` — الحسابات (`calc.ts`)، التنسيق، المزامنة (`sync.ts`)، النسخ الاحتياطي، إكسل، جسر المنصات.
- `src/screens/` — الشاشات. `src/ui/` — المكوّنات. `src/print/` — قوالب الطباعة.
- `electron/` — نسخة ويندوز. `android/` — غلاف أندرويد (WebView بلا Gradle). `server/` — الموقع وخادم المزامنة.

### كيف تعمل المزامنة
كل سجل يحمل وقت آخر تعديل. يرسل الجهاز ما تغيّر عنده ويستلم ما تغيّر عند غيره منذ آخر زيارة (`POST /api/sync`). عند تعارض يفوز الأحدث. المخزون لا يُخزَّن كرقم بل يُحسب من حركات المخزون، فلا تتعارض عمليات البيع من جهازين.
