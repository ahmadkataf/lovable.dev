# كاسب (Kaseb) — نقطة بيع حديثة للمحلات

**كاسب** برنامج كاشير يعمل بلا إنترنت، للمحلات الصغيرة والمتوسطة: بقالة، صيدلية، مكتبة، ملابس، قطع غيار… يُباع لصاحب المحل
بترخيص **دائم** لجهاز واحد (النص الافتراضي للسعر: **35$** مرة واحدة، والبيانات محلية مجاناً)، مع اشتراك اختياري في **التخزين السحابي**
(**35$ سنوياً**: نسخة احتياطية مضغوطة تُرفع تلقائياً كل يوم وتُستعاد من أي جهاز). يعمل على **ويندوز** (ملف تثبيت) و**أندرويد** (ملف APK) ومن المتصفح للعرض.
الواجهة عربية أولًا (من اليمين لليسار) مع الإنجليزية كلغة ثانية، ووضع ليلي، ومصممة للمس على الهاتف وللوحة المفاتيح على الكمبيوتر.

## المزايا
- **شاشة البيع**: بحث سريع، أصناف مفضلة، خصومات على السطر وعلى الفاتورة، ضريبة، تعليق الفاتورة واستئنافها، دفع نقدي / بطاقة / آجل، طباعة ومشاركة الإيصال (واتساب).
- **الباركود**: قارئ USB/بلوتوث على الكمبيوتر، و**كاميرا الهاتف** كقارئ احترافي داخل التطبيق، مع توليد باركود داخلي للأصناف التي لا باركود لها وطباعة الملصقات.
- **الأصناف والمخزون**: أصناف وتصنيفات ووحدات وكسور الكمية، حركة المخزون بالكامل (شراء، بيع، تسوية، جرد)، تنبيه نقص المخزون، الموردون والمشتريات.
- **العملاء والديون**: دفتر ديون لكل عميل، تسديد جزئي، كشف حساب.
- **الورديات والمصاريف**: فتح وإغلاق الوردية مع فرق الصندوق، تسجيل المصاريف بتصنيفات، تقرير الوردية.
- **التقارير**: المبيعات والأرباح حسب اليوم/الأسبوع/الشهر، الأصناف الأكثر مبيعًا، الكاشيرين، تصدير CSV.
- **المستخدمون**: مدير وكاشير، قفل بالرقم السري، صلاحيات مختلفة.
- **الإعدادات والنسخ الاحتياطي**: بيانات المحل، شكل الإيصال، الطابعة، العملة والكسور، نسخة احتياطية كاملة واستعادتها.
- **وحدات بيع وأسعار جملة**: بيع بالكرتونة/العلبة بسعر وباركود خاصين والمخزون بالقطعة، سعر جملة يُطبَّق تلقائياً لعملاء الجملة، باركود الميزان (وزن/سعر)، تاريخ انتهاء مع تنبيه.
- **عملة ثانية**: استلام بالدولار (أو أي عملة) بسعر صرف، والباقي بالعملتين على الإيصال.
- **نقاط ولاء**: كسب نقاط على كل فاتورة واستبدالها كخصم، رصيد النقاط في صفحة العميل.
- **فاتورة A4 ورمز ZATCA**: فاتورة ضريبية مفصّلة للطباعة مع رمز QR بصيغة TLV (السعودية) عند تفعيل الضريبة.
- **سجل النشاط وصلاحيات الكاشير**: من غيّر السعر أو أعطى خصماً أو أرجع فاتورة، وصلاحيات دقيقة للكاشير (خصم، تعديل سعر، إرجاع، رؤية التكلفة، تعديل الأصناف، تسوية المخزون، السجل).
- **إعادة الطلب**: قائمة النواقص تتحول إلى أمر شراء بضغطة، وإرسال الإيصال أو تذكير الدين للعميل على واتساب.
- **يعمل بلا إنترنت** تمامًا؛ الإنترنت لازم فقط للتفعيل الأول ولفحص دوري للترخيص (وللرفع السحابي عند الاشتراك).

## سياسة المحتوى
كاسب **لا يبيع منتجات التبغ والدخان** بكل أنواعها (سجائر، معسل، أرجيلة، سجائر إلكترونية/فيب، نيكوتين، وماركاتها) **ولا المشروبات الكحولية** (خمر، بيرة، نبيذ،
ويسكي، فودكا، عرق، وماركاتها) بالعربية والإنكليزية. أي منتج أو تصنيف باسم أو وصف من هذا النوع يُرفض عند الإضافة والاستيراد والاستعادة، مع رسالة واضحة:
**هذا المنتج بيعه حرام**. القاعدة ثابتة في البرنامج ولا يمكن تعطيلها من الإعدادات. الكحول الطبي والمعقّمات والمشروبات الخالية من الكحول (شعير) مسموحة.

## المنصات
| المنصة | الملف | ملاحظات |
|---|---|---|
| ويندوز 10/11 (64 بت) | `Kaseb-POS-Setup-<الإصدار>.exe` | مثبِّت عادي (اختيار المجلد، اختصار على سطح المكتب وقائمة ابدأ). الطباعة مباشرة على طابعة الإيصالات الحرارية (58/80 مم). |
| أندرويد 7+ | `Kaseb.apk` (و`Kaseb.aab` لمتجر Google Play) | الكاميرا كقارئ باركود، الطباعة عبر نظام الطباعة في أندرويد، المشاركة لواتساب. |
| المتصفح | مجلد `dist` | للعرض والتجربة فقط (بدون حماية ترخيص حقيقية). |

## الحصول على الملفات (GitHub Actions)
1. من صفحة المستودع افتح **Actions** ← **Build Kaseb POS** ← **Run workflow**.
2. اكتب رقم الإصدار (مثل `1.0.0`) واضغط **Run workflow**.
3. بعد انتهاء التشغيل (نحو 10 دقائق) افتحه وانزل إلى **Artifacts**:
   - `kaseb-windows`: ملف التثبيت لويندوز.
   - `kaseb-android`: ملف `Kaseb.apk` (وملف `.aab` لمتجر Google Play إن توفّر).
   - `kaseb-web`: نسخة المتصفح.

## الإعداد لأول مرة (بالترتيب)
1. **انشر السرفر** (خادم التراخيص وصفحة الأكواد): اتبع `pos/server/README.md`. ستحصل على عنوان مثل
   `https://kaseb-api.<اسمك>.workers.dev` وكلمة مرور لوحة الأكواد.
2. **أضف متغيّر المستودع** `KASEB_API` بعنوان السرفر: **Settings ← Secrets and variables ← Actions ← Variables ← New repository variable**.
   بدون هذا المتغيّر يتوقف البناء برسالة واضحة.
3. (اختياري لكنه مهم للأندرويد) **مفتاح توقيع ثابت** حتى تُقبل التحديثات فوق النسخة المثبتة ويعمل حظر النسخ المعدّلة:
   شغّل `npm run build:apk` مرة على جهازك فيُنشأ `pos/android/release.keystore`، ثم أضف ثلاثة Secrets:
   `KASEB_KEYSTORE_BASE64` (الملف مشفّرًا بـ base64)، `KASEB_KEYSTORE_PASSWORD` (الافتراضي `kasebpass`)، `KASEB_KEY_ALIAS` (الافتراضي `kaseb`).
   **احتفظ بالملف في مكان آمن ولا ترفعه إلى المستودع** (مُستثنى في `.gitignore`).
4. **شغّل** سير العمل **Build Kaseb POS** كما في الفقرة السابقة.

## التطوير على جهازك
```bash
cd pos
npm install                 # مرة واحدة
npm run dev                 # تشغيل التطبيق في المتصفح (http://localhost:5173) — وضع تجريبي بلا تفعيل
npm test                    # اختبارات الوحدات (vitest)
npm run test:shell          # اختبارات قشرة ويندوز ومولّد الأيقونات
npm run icons               # يولّد الأيقونات من public/icon.svg (يحتاج Chromium من playwright-core)
npm run electron:dev        # تشغيل نسخة ويندوز/سطح المكتب من الكود الحالي
npm run build:win           # مثبّت ويندوز في pos/release/ (يُبنى على ويندوز؛ على لينكس يُنتج النسخة غير المحزومة بـ build:win:dir)
npm run build:apk           # ملف APK في pos/android/build/ (يحتاج ANDROID_HOME وJDK 17+ وPython مع Pillow)
npm run codes:dev           # تشغيل السرفر وصفحة الأكواد محليًا
```
لبناء نسخة مرتبطة بسرفرك محليًا مرّر العنوان والمفتاح العام:
`POS_API=https://... POS_LICENSE_PUBLIC_KEY=<hex> npx vite build`
(المفتاح العام من `GET /api/public-key` على السرفر).

## كيف يعمل التفعيل، وما هي صفحة الأكواد
عند أول تشغيل يعرض التطبيق **رمز الجهاز** (مثل `AB3K-7PQ2`) وحقلًا لإدخال **كود التفعيل** `XXXX-XXXX-XXXX`، وزرًا لبدء **تجربة مجانية**
(عدد أيامها تحدده أنت) وزر **اشترِ عبر واتساب** يفتح محادثة معك تتضمن رمز الجهاز. عندما يدخل العميل الكود يتصل التطبيق بالسرفر مرة واحدة،
فيربط السرفر الكود بهذا الجهاز ويعيد **رمز ترخيص موقّعًا** بمفتاح السرفر الخاص؛ يُحفظ هذا الرمز خارج صفحة التطبيق (مشفّرًا بمفتاح نظام ويندوز،
وفي تخزين التطبيق الخاص على أندرويد). بعدها يعمل البرنامج بلا إنترنت، ويعيد الفحص في الخلفية كل بضع ساعات عندما يتوفر اتصال.
إن بقي الجهاز بلا اتصال أطول من **مدة السماح** (الافتراضي 10 أيام) يتوقف حتى يتصل مرة ويتأكد أن الترخيص ما زال ساريًا. يمكن للعميل نقل
ترخيصه بنفسه إلى جهاز جديد من شاشة التفعيل (حتى 3 مرات)، ويمكنك أنت نقله أو إلغاؤه في أي وقت.

**صفحة الأكواد** هي لوحة التحكم الخاصة بك على السرفر (`<عنوان السرفر>/admin`، تعمل من الهاتف، بكلمة المرور التي اخترتها عند النشر).
منها تنشئ الأكواد (دفعة من 1 إلى 100، دائمة أو لمدة محددة، لجهاز أو أكثر) وتنسخها أو تطبعها كبطاقات، وتبحث عن أي كود أو جهاز أو رمز جهاز،
وترى لكل كود أجهزته وآخر ظهور وإصدار التطبيق، وتُلغي كودًا أو تعيده، وتحرر جهازًا لينتقل العميل إلى جهاز آخر، وتمدد مدة كود،
وتتابع إحصاءات التفعيلات والتجارب. اطلب الكود من العميل عند البيع، أو أنشئه أمامه وأرسله له على واتساب.

## تغيير نص السعر ورقم واتساب
رقم واتساب الافتراضي للتفعيل والدعم هو `963996489504` (0996489504). لتغييره أو تغيير السعر:
افتح صفحة الأكواد ← تبويب **إعدادات** ← عدّل **السعر** (نص حر مثل `35$` أو `150,000 ل.س`) و**رقم واتساب** (بالصيغة الدولية بلا +)
و**أيام التجربة** و**مدة السماح** و**رسالة للعملاء** تظهر في شاشة التفعيل. تُحفظ الإعدادات على السرفر وتظهر في التطبيقات عند فحصها التالي
دون إعادة بناء.

## الحماية من التلاعب (باختصار)
- **ويندوز**: التطبيق محزوم في `app.asar` ومُفعّل عليه **Electron fuses**: التحقق من سلامة الحزمة (أي تعديل على ملفات التطبيق يمنعه من
  التشغيل)، والتحميل من الحزمة فقط، وإغلاق أبواب Node (`ELECTRON_RUN_AS_NODE`، `NODE_OPTIONS`، `--inspect`).
- **أندرويد**: يرسل التطبيق بصمة شهادة توقيع APK (SHA-256) مع كل طلب؛ أضف بصمتك في صفحة الأكواد ← إعدادات ← **توقيع أندرويد** فيرفض
  السرفر أي APK أُعيد توقيعه (أي عُدِّل). تظهر البصمة في مخرجات `build:apk` (سطر `SHA-256 digest`).
- **الرموز موقّعة** بمفتاح Ed25519 لا يغادر السرفر؛ التطبيق يحمل المفتاح العام فقط ويرفض أي رمز غير موقّع به أو لجهاز آخر.
- **مدة السماح**: يجب أن ينجح فحص واحد قبل انتهائها، مع حماية من إرجاع ساعة الجهاز.
- يبقى الكود بحوزتك أنت وحدك: إلغاؤه من اللوحة يوقف التطبيق عند أول فحص.

## أين تُحفظ بيانات المحل
كل بيانات المحل (الأصناف، المبيعات، العملاء، الورديات…) تُحفظ **على الجهاز نفسه** في قاعدة IndexedDB داخل التطبيق، ولا تُرسل إلى أي
سرفر. على ويندوز تحت `%APPDATA%\Kaseb POS`، وعلى أندرويد في تخزين التطبيق الخاص. لذلك:
- انصح العميل بأخذ **نسخة احتياطية** دوريًا من **الإعدادات ← النسخ الاحتياطي** (ملف واحد يُحفظ حيث يختار: فلاشة، Google Drive، واتساب…)،
  وبإستعادتها من الشاشة نفسها عند تغيير الجهاز.
- حذف التطبيق من أندرويد يحذف البيانات؛ إزالة التثبيت على ويندوز **لا** تحذفها.

## خريطة المجلدات
```
pos/
  src/                    التطبيق (React + TypeScript + Vite): الشاشات، قاعدة البيانات، المكتبات، الترجمة
  public/                 icon.svg والأيقونات المولّدة وmanifest
  build/                  أيقونات ويندوز/أندرويد المولّدة (icon.ico, icon.png, icon-fg/bg.png) — تُنشأ بـ npm run icons
  electron/               قشرة ويندوز: main.cjs (النافذة والجسر) وpreload.cjs (window.pos) وlib.cjs (منطق مُختبَر)
  electron-builder.json   إعداد مثبّت ويندوز (NSIS, x64)
  android/                قشرة أندرويد بلا Gradle: AndroidManifest.xml وMainActivity.java (WebView + كاميرا + الجسر PosAndroid)
  scripts/                make-icons.mjs (الأيقونات)، after-pack.cjs (fuses)، build-apk.sh وandroid-res.py (أندرويد)
  server/                 خادم التراخيص وصفحة الأكواد (Cloudflare Worker + D1) — انظر server/README.md
  docs/                   ARCHITECTURE.md (بنية التطبيق) وLICENSE-SPEC.md (مواصفة التفعيل)
  dist/ release/ android/build/   مخرجات البناء (غير مرفوعة إلى المستودع)
.github/workflows/build-pos.yml   سير العمل الذي يبني الويب وويندوز وأندرويد
```
