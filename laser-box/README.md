# مولّد صناديق الليزر — Laser Box Generator

تطبيق ويب يولّد صناديق خشبية جاهزة للقص بليزر CO2: تختار الشكل، تكتب القياسات والسماكة، وتنزّل ملف **SVG** أو **DXF** بالمليمتر يُفتح مباشرة في LightBurn أو RDWorks أو Inkscape.

## الأشكال الجاهزة
| الشكل | ما يميّزه |
|---|---|
| صندوق مغلق | ستة أوجه بتعشيق أصابع |
| صندوق مفتوح | خمسة أوجه، مفتوح من الأعلى |
| صندوق بغطاء منزلق | غطاء ينزلق في شقّين جانبيين مع فتحة إصبع |
| علبة بغطاء منفصل | قاعدة وغطاء يُلبَس فوقها (كعلبة الأحذية) |
| صندوق بغطاء مفصلي | ستّ قطع: الغطاء لوح واحد له لسانان يدوران في ثقبي الجانبين، بلا محور |
| صندوق بمفصل مرن | الخلفية والغطاء قطعة واحدة تنثني بشبكة قصّات (living hinge) |
| منظّم بفواصل | فواصل متقاطعة تدخل في شقوق الجدران |
| صينية بمقابض | صندوق منخفض مع فتحتي مقبض |

## ما يضبطه المستخدم
- العرض والعمق والارتفاع (خارجية أو داخلية — تُضاف السماكات تلقائياً).
- سماكة الخامة، عرض الشقّ (kerf) ويُعوَّض تلقائياً ليكون التعشيق محكماً، عرض الأصبع.
- خيارات كل شكل: خلوص الغطاء، عرض لسان المفصل وخلوصه، نصف قطر الانحناء وكثافة المفصل المرن، عدد الفواصل، أبعاد المقبض…
- عرض اللوح والمسافة بين القطع (تُرصّ القطع تلقائياً في صفوف).
- الرابط يحمل التصميم كاملاً، فيمكن مشاركته أو حفظه.

## التشغيل
```bash
cd laser-box
npm install
npm run dev              # تطوير
npm run build            # إنتاج → dist/
npm run build:artifact   # ملف واحد → dist/artifact.html
npm run build:apk        # تطبيق أندرويد → android/build/LaserBox.apk (يحتاج ANDROID_HOME وJDK 17+)
npm test                 # اختبارات محرّك الهندسة
```

## البنية
- `src/geom.ts` — الهندسة: اتحاد المستطيلات (الأصابع والشقوق تندمج بلا قصّات مكرّرة)، الأقواس (bulge)، تعويض الـ kerf، مسارات SVG.
- `src/joints.ts` — بناء اللوح: حواف ذكر/أنثى/مستوية بعدد أصابع فردي، قصّات وثقوب إضافية.
- `src/templates.ts` — الأشكال الجاهزة وعوامل كل منها.
- `src/layout.ts` — رصّ القطع على اللوح. `src/export.ts` — كتابة SVG وDXF (R12).
- `src/main.ts` — الواجهة (عربية، تعمل على الهاتف، معاينة مع تكبير وسحب).
- `android/` — غلاف أندرويد (WebView) يحفظ ملفات SVG وDXF عبر نافذة الملفات في النظام؛ `scripts/build-apk.sh` يبنيه بأدوات build-tools فقط بلا Gradle.

## نصائح للقص
- قِس سماكة اللوح بالقدمة؛ «3 مم» التجارية غالباً 2.7–2.9 مم.
- اقصّ مربّع اختبار 20 مم واقِس عرض الشقّ، ثم اكتبه في خانة kerf.
- جرّب المفصل المرن على قطعة صغيرة قبل القطعة النهائية؛ الأبلكاش أطوع من الـ MDF.
