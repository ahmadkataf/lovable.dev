# مولّد صناديق الليزر — Laser Box Generator

تطبيق ويب يولّد صناديق خشبية جاهزة للقص بليزر CO2: تختار الشكل، تكتب القياسات والسماكة، وتنزّل ملف **SVG** أو **DXF** أو **AI 8** (Illustrator 8، الصيغة التي يقرؤها RDWorks) بالمليمتر يُفتح مباشرة في LightBurn أو RDWorks أو Inkscape.

داخل نافذة Claude لا يُسمح بحفظ ملفات .ai و.dxf مباشرة، فتُحفظ مضغوطة باسم ينتهي بـ `.ai.zip` أو `.dxf.zip`؛ افتح الملف المضغوط تجد الملف بداخله. تطبيق الأندرويد (APK) يحفظها مباشرة.

الزخارف المتاحة: دوائر، شقوق عمودية، نافذة، قلوب، شبكة معيّنات، نجوم ثمانية. الزخارف اليدوية الدقيقة (الأرابيسك) فنّ مرسوم لا يولّده البرنامج؛ استوردها في RDWorks فوق القطعة إن أردتها.

## ما يضبطه المستخدم
- العرض والعمق والارتفاع (خارجية أو داخلية — تُضاف السماكات تلقائياً).
- سماكة الخامة، عرض الشقّ (kerf) ويُعوَّض تلقائياً ليكون التعشيق محكماً، عرض الأصبع.
- خيارات كل شكل: خلوص الغطاء، عرض لسان المفصل وخلوصه، نصف قطر الانحناء وكثافة المفصل المرن، عدد الفواصل، أبعاد المقبض…
- عرض اللوح والمسافة بين القطع (تُرصّ القطع تلقائياً في صفوف).
- الرابط يحمل التصميم كاملاً، فيمكن مشاركته أو حفظه.
- **تصغير أو تكبير التصميم كاملاً** (📐): بنسبة من الحجم الحالي أو بقياس محدّد يطلبه الزبون. تتغيّر كل قياسات التصميم معاً، وتبقى السماكة والخلوص وقياسات الأشياء الحقيقية (الصحن، الصورة، الكرت، الشمعة…) كما هي إلا إن طلبت تغييرها، ثم يُصحَّح ما لا يصلح بالنسبة نفسها (شفة أرقّ من تعشيقها، صحن لا يتّسع) بأقلّ تغيير، ويُكتب ما تغيّر ولماذا مع زرّ تراجع. لا تصغّر ملف القصّ في RDWorks: الشقوق تصغر معه فتصبح أضيق من اللوح.
- **💲 التكلفة**: كل خامة في التصميم على لوحها (الأساسي 122 × 244 سم بـ 11$ افتراضياً، والمرآة والذهبي والشفّاف… لكلٍّ لوحه وسعره)؛ يحسب كم قطعة يطلع اللوح الواحد بالرصّ، وحصّة القطعة من اللوح، ولعدد مطلوب كم لوحاً تشتري، ومشروع من عدة تصاميم بمجموعه وألواحه. سعر صرف واحد للتطبيق كلّه، وكل سعر يُعرض بالدولار والليرة (`src/cost.ts`).
- **🔍 بحث** باسم المنتج في نافذة التصاميم، بأي إملاء (مبخره/مبخرة).
- **🔧 صحّح تلقائياً** في مربّع الأخطاء الأحمر: يبحث عن أقرب قياسات تصلح للقصّ، ويترك القياس الذي كتبته للتوّ والسماكة والخلوص وقياسات الأشياء كما هي (`src/scale.ts`).

## التشغيل
```bash
cd laser-box
npm install
npm run dev              # تطوير
npm run build            # إنتاج → dist/
npm run build:artifact   # ملف واحد → dist/artifact.html
npm run build:apk        # تطبيق أندرويد → android/build/LaserBox.apk للمشاركة وLaserBox.aab لـ Google Play (يحتاج ANDROID_HOME وJDK 17+ وbundletool)
npm test                 # اختبارات محرّك الهندسة
```

اسم الحزمة الدائم `io.github.ahmadkataf.laserbox`، ويجب أن يوقَّع كل إصدار بالمفتاح نفسه، وإلا رفض الهاتف التحديث ورفض Google Play الرفع. المفتاح لا يوضع في هذا المستودع لأنه عام؛ أعطه للبناء بأحد المتغيّرين:
- `ANDROID_KEYSTORE_BASE64`: ملف المفتاح ‎.p12 مرمّزاً base64 (يناسب متغيّرات بيئة السحابة)، أو `ANDROID_KEYSTORE`: مساره.
- مع `ANDROID_KEYSTORE_PASSWORD`، و`ANDROID_KEY_ALIAS` إن لم يكن `laserbox`.

بدونهما يُوقَّع البناء بمفتاح مؤقّت ويكتب تحذيراً: يصلح للتجربة فقط. بصمة المفتاح الدائم (SHA-256): `BD:89:56:C1:15:44:E0:C6:E2:D2:97:B7:1A:BC:FF:77:8B:F9:BA:92:F0:D7:59:03:39:5C:DB:A3:3B:E0:30:95`. زِد `versionCode` في `android/AndroidManifest.xml` مع كل إصدار.

## البنية
- `src/geom.ts` — الهندسة: اتحاد المستطيلات (الأصابع والشقوق تندمج بلا قصّات مكرّرة)، الأقواس (bulge)، الأقراص والشقوق المدوّرة، المفاصل المرنة، تعويض الـ kerf، مسارات SVG.
- طبقتان في الملفات: أحمر للقصّ وأزرق لخطوط الحفر الإرشادية (طبقة ENGRAVE في DXF).
- `src/joints.ts` — بناء اللوح: حواف ذكر/أنثى/مستوية بعدد أصابع فردي، قصّات وثقوب إضافية.
- `src/templates.ts` — الأشكال الجاهزة وعوامل كل منها.
- `src/cost.ts` — الرصّ على اللوح لعدّ ما يطلع منه، وحساب التكلفة بالخامة وللمشروع، والعملتان، والبحث العربي.
- `src/scale.ts` — تصنيف كل عامل (قياس في التصميم، قياس شيء حقيقي، سماكة أو خلوص، عدد، تشغيل/إيقاف، اختيار، زاوية)، وتكبير التصميم أو تصغيره، والتصحيح التلقائي للأخطاء.
- `src/layout.ts` — رصّ القطع على اللوح. `src/export.ts` — كتابة SVG وDXF (R12) وAI 8 (PostScript، الأقواس منحنيات بيزييه، طبقة قصّ حمراء وطبقة حفر زرقاء).
- `src/main.ts` — الواجهة (عربية، تعمل على الهاتف، معاينة مع تكبير وسحب).
- `android/` — غلاف أندرويد (WebView) يحفظ ملفات SVG وDXF عبر نافذة الملفات في النظام؛ `scripts/build-apk.sh` يبنيه بأدوات build-tools فقط بلا Gradle.

## الفحص قبل القص
- البرنامج يحسب عرض الأصابع الفعلي بعد تقريبه لعدد فردي، ويرفض الملف إن صار أرقّ من السماكة أو إن كان أصبع الزاوية سيتّصل بشريحة رفيعة.
- اختبار شبكي يولّد كل الأشكال على آلاف التركيبات (السماكة، الـ kerf، الأصابع، القياسات، حدود كل خيار) ويتحقق أن كل قطعة قطعة واحدة بلا تقاطع ذاتي وأن كل ثقب داخلها بهامش 0.8 مم على الأقل.

## نصائح للقص
- قِس سماكة اللوح بالقدمة؛ «3 مم» التجارية غالباً 2.7–2.9 مم.
- اقصّ مربّع اختبار 20 مم واقِس عرض الشقّ، ثم اكتبه في خانة kerf.
- جرّب المفصل المرن على قطعة صغيرة قبل القطعة النهائية؛ الأبلكاش أطوع من الـ MDF.
