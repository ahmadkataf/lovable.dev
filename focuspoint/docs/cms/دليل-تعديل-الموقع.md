# دليل تعديل الموقع من لوحة التحكم

كل نصوص وصور الموقع والتطبيق صارت تتعدّل من لوحة التحكم، والتعديل يطلع فوراً عند الزبائن (بالموقع وبالتطبيق).

## الوصول
1. افتح لوحة الفريق وسجّل دخول **بحساب المدير** (حساب الموظف ما بيشوف هالقسم).
2. اضغط تبويب **«الموقع»** (تحت على الموبايل، أو بالقائمة الجانبية على الكمبيوتر).

## الأقسام
| القسم | شو فيه |
|---|---|
| الهوية والتواصل | اسم المركز، الرقم، العنوان، إنستغرام، الدوام، الواتساب، الشعار، روابط فيسبوك/تيك توك/الإيميل |
| شريط الإعلان | شريط صغير فوق الموقع لخبر أو عرض أو عطلة (تشغيل/إطفاء) |
| الصفحة الرئيسية | الواجهة والصورة، شريط الأرقام، المميزات، المساحات، «كيف بتحجز»، معرض الصور، الدوام والعنوان، الأسئلة المتكررة، دعوة الحجز، وترتيب/إخفاء الأقسام |
| صفحة المساحات | نصوص وصور مجموعات المساحات (غرف خاصة، قاعة اجتماعات، مساحة مفتوحة) |
| صفحة من نحن / تواصل معنا / أسفل الموقع | نصوص هالصفحات |
| الحجز والدفع | النصوص اللي بيشوفها الزبون وقت الحجز والدفع |
| رسائل الإشعارات | نص الإشعارات اللي بتوصل للزبون والفريق |
| محركات البحث والمشاركة | العنوان والوصف اللي بيطلعوا بغوغل ولما حدا يشارك الرابط |
| اللون | اللون الأساسي للموقع |
| خيارات الحجز والدفع | إيقاف الحجز مؤقتاً، شام كاش، الدفع عند الوصول، كم يوم لقدّام، التذكير، الإلغاء |

صور كل غرفة بتتعدّل من **«القاعات»** ← اختار الغرفة ← **«الصور»**.

## التعديل خطوة بخطوة
1. افتح القسم، واضغط على العنوان الفرعي اللي بدك ياه (بيفتح ويسكّر).
2. عدّل النص. الكلمات بين `{ }` مثل `{phone}` بتتعبّى لحالها من بيانات المركز — اتركها متل ما هي، أو أضف وحدة من زر **«+ معلومة تلقائية»**.
3. الصورة: **«تغيير الصورة»** ← اختار من الموبايل أو الكمبيوتر (بتتصغّر لحالها). اكتب وصف قصير للصورة.
4. اضغط **«حفظ»** تحت. إذا في غلط، بيطلع تحت الحقل بالأحمر وما بينحفظ شي.
5. اضغط **«عرض في الموقع»** لتشوف النتيجة.

## إذا صار غلط
- **«تراجع عن آخر حفظ»**: بيرجّع القسم متل ما كان قبل آخر حفظ (بيتذكّر آخر 20 حفظ).
- **«استعادة الأصل»**: بيرجّع القسم للنصوص والصور الأصلية تبع الموقع.
- إذا انقطع النت: التعديلات اللي كتبتها بتضل محفوظة على جهازك، واحفظ لما يرجع النت.

## نصائح للاجتماع
- جرّب قبل الاجتماع بربع ساعة: عدّل كلمة بالصفحة الرئيسية، احفظ، شوفها بالموقع، وبعدين **«تراجع»**.
- خلي الموقع مفتوح على جهاز تاني (أو تبويب تاني) لتوري العميل التغيير مباشرة — حدّث الصفحة بعد الحفظ.
- عدّل قسم قسم واحفظ كل واحد لحاله.
